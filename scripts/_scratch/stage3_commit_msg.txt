Phase 1f-7 Stage 3: flat_last backbone fine-tune (PASSES 6-seed live gate)

DeepSeek consult #3 verdict: the readout-only path was exhausted because
backbone_v2_full.pt's flat_last [6144] is kind-isolated -- no readout (shared
or decomposed) can hold conv/text/code in one cross-kind logit space. The fix
is a backbone retrain that teaches flat_last a common cross-kind query-doc
relevance subspace. This is the CHEAP fine-tune diagnostic: lightly fine-tune
the existing backbone (8 epochs, all 19.5M params, lr 1e-5) with a margin loss
on flat_last over the onyx doc ring, via a THROWAWAY slim query-conditioned
readout (Linear(6144,384) + cos(z,q)/T, discarded after).

Replay strategy: pre-state replay, truncated-BPTT-depth-1. Each kept slot's
pre-step WM state (slots_pre_state) + EXACT step-input embedding
(slots_step_input) are captured on the slot; the fine-tune seeds
states = slots_pre_state[k] (detached) and re-steps ONLY slots_step_input[k]
WITH grad through layer.step -> reproduces slots_h_raw within fp16 epsilon AND
backprops into the shared backbone (W_A/W_B). No cross-slot BPTT, no overflow/
drop-gap (the pre-state encodes all prior history).

The fidelity fix (the key correctness piece): retrieved CODE docs are injected
"by MEANING" (the orchestrator steps embed(embed_text), not embed(summary)),
while slot.text stores the summary string. Re-embedding slot.text at trace-build
diverged from the stepped vector for ~20% of retrieved slots, breaking the
replay (max-abs-diff 0.2421 > atol 0.15). Capturing the EXACT step-input u on
the slot (post-pin, pre-SSM) and replaying from it closes the gap: fidelity
max-abs-diff 0.0002 (essentially exact). Loss dropped smoothly 2.51 -> 0.46
across 8 epochs (NOT stuck at the 2.49 margin ceiling -- the per_kind_bodies
collapse signature).
